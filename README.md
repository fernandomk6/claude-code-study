# Claude Code Study

Repositório de estudos sobre Claude Code, com conteúdo organizado por seções que cobrem desde os fundamentos até recursos avançados (MCP, Skills, Hooks e Rules).

## Estrutura do repositório

O conteúdo principal está em:

- `/Claude Code do Zero ao avançado, MCP, Skills, hooks, Rules`
  - `Seção 1 - Iniciando sua jornada`
  - `Seção 2 - Evoluindo com claude code`
  - `Seção 3 - Poder ao claude code`
  - `Seção 4 - Claude code avançado`
  - `Seção 5 - Claude code evoluindo e uso real`
  - `Extra`
  - `projeto-1` (projeto prático em Next.js com formulário de contato, depoimentos e skills do Claude Code)

## Objetivo

Centralizar materiais, exemplos e exercícios para aprendizado prático de Claude Code, evoluindo de conceitos básicos até fluxos avançados de automação e produtividade.
