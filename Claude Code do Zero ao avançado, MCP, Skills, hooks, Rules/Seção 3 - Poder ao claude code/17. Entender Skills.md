# Entender skills

Skill é um pacote de habilidade especifico.

- Skill possuem um uso por demanda.

Skill somente são usadas quando invocadas ou quando o claude infere que elas são necessárias.

- Skills podem ser comandos

Você pode criar uma skill, por exemplo "Enviar email" e chamar essa skill no terminal
usando o comando /send-email.

Skills de projeto ficam versionadas no git (boas para compartilhar com o time), enquanto skills globais são pessoais e seguem você entre projetos.

## Bons sites para obter skills da comunidade

[skills.sh](https://www.skills.sh/)

### Toda skill é um slash command?

Por padrão sim, mas existe um campo de frontmatter que remove isso:
```yaml
---
name: legacy-system-context
description: Explica como o sistema legado funciona
user-invocable: false
---
```

Com user-invocable: false, a skill some do menu /

### Uma skill pode gerar mais de um slash command?

Skills de plugin com name diferente do diretório.
```yaml
# my-plugin/skills/review/SKILL.md
---
name: fancy
description: Revisão de código estilizada
---
```

Isso cria:

/my-plugin:fancy (com namespace)
