# Entendo o modo Agent e Plan 

Use `shift + tab` para mudar o modo do agent.

## Modo Agent (padrão)

Você pede e ele faz.
Executa a tarefa diretamente.

### Quando usar?

Quando você sabe exatamente o que fazer.

## Plan mode

É um **permition mode**.

Claude pesquisa e propõe alterações sem editar seus arquivos de origem.
Pode ler, pesquisar e executar comandos de exploração, depois apresenta
um plano para aprovação antes de tocar em qualquer coisa.

### Quando usar?

Quando você não sabe exatamente o que fazer.
É uma ajuda no planejamento.
