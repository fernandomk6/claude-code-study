### LLMs

Modelo de linguagem.
Significa: Large Language Model / Modelo de linguagem grande

É um modelo de linguagem treinado para entender e gerar textos em linguagem natural.
Exemplos:
- GPT
- Claude
- Gemini

É o cérebro.
É o motor do chatbot.

### Token
Unidade mínima de texto que um modelo processa.
Pode ser uma palavra, parte dela ou um caractere.
Exemplo: a palavra "gato" pode ser 1 token; "extraordinario" pode virar vários tokens.

### Prompt
O texto de entrada dado a um modelo para obter uma resposta.
Exemplo: "Explique fotossíntese para uma criança de 8 anos."

### Prompt engeneering
Técnicas para criar e refinar prompts para obter respostas melhores ou mais precisas de um modelo.

### Context window
Quantidade de texto (em tokens) que um modelo consegue "lembrar" e processar de uma 
vez durante a conversa.

Limite de tokens da janela (seção / conversa)

### Fine-tuning

Ajuste fino.
Processo de treinar um modelo já pronto com dados específicos para especializa-lo
em uma tarefa ou domínio.
Exemplo: ajustar um LLM genérico para responder perguntas jurídicas.

### Hallucination (Alucinação)
Quando um modelo gera informações incorretas ou inventadas, mas apresenta como se fossem
verdadeiras.

### Embeddings
Representação numérica (vetores) de palavras, frases ou dados, que captura
significado e permite comparar similaridade. Exemplo: as palavras "rei" e "rainha"
têm embeddings próximos em significado.

### IA generativa
IA capaz de criar conteúdo novo (texto, imagem, áudio, código) em vez de apenas
classificar ou prever. 
Exemplo: chatGPT gerando texto ou Midjourney gerando imagens.

### Agente
Sistema que percebe, decide e age de forma autônoma para atingir um objetivo.

### Function calling
Capacidade de um modelo chamar funções ou ferramentas externas (buscar na web,
rodar código) para complementar sua resposta.

### RAG 
Retrievel-Augmented Generation

Técnica em que o modelo busca informações em uma base de dados externa antes
de gerar a resposta, aumentando precisão e atualidade.
Exemplo: Um chatbot que consulta a documentações da empresa antes de responder.

### MCP (Model context protocol)
É um protocolo como o http.

Protocolo que permite conectar modelos de IA a ferramentas e fontes de dados externas
de forma padronizada.

### Modelo (Opus, sonnet, Haiku etc)
LLM: Claude (também chamado de família)
Modelo: Opus, Sonnet, Haiku (Claude Opus 5.5)
Agente: Claude code (utiliza o modelo para executar
