# Entendendo hooks

## Definição

Hooks são comandos shell definidos pelo usuário, endpoints HTTP, chamadas de ferramentas MCP, prompts LLM ou subagentos que executam automaticamente em pontos específicos do ciclo de vida do Claude Code.

Um hook é disparado pelo claude em algum momento do ciclo de vida de uma seção.
Uma seção possui eventos, como onStartSession, onCloseSession, onPrompt etc, e 
nesses eventos você pode chamar um hook. O hook pode executar ações, bloquear acessos e etc.

Evento — o momento do ciclo de vida em que ele dispara (PreToolUse, PostToolUse, SessionStart, UserPromptSubmit, Notification, Stop, entre outros)

Matcher (opcional) — um filtro regex que restringe quando o hook roda, por exemplo só em chamadas da ferramenta Bash, ou só em Edit|Write

Ação — o que executa, geralmente um comando shell (mas também pode ser um prompt enviado a um modelo leve para avaliação)

## Para que servem na prática:

Guardrails de segurança — um hook PreToolUse pode bloquear um rm -rf, um push --force ou uma migração destrutiva, não importa como o agente tenha "justificado" a ação.
