# Conhecendo MCP server

## Definição

Model Context Protocol (MCP).
permite que o Claude Code use ferramentas além do seu conjunto integrado,
como pesquisar um rastreador de problemas, consultar um banco
de dados ou controlar um navegador web. Essas ferramentas vêm de servidores
MCP, que são executados em sua máquina ou como serviços hospedados.


Um MCP conecta o claude code com a ferramenta.
É um protocolo para agentes de IA se comunicar com servidores externos.

É um conector. Conecta seu agente a ferramenta.
