# Entendo e criando subagents
Um subagent é uma sub instancia. Executa em contexto separado.
Deve ser criado para executar tarefas especificas.

O contexto principal pode chamar vários sub-agents.

Eu defino o que um sub-agent pode ou não fazer.

Os agentes são criados dentro da pasta .claude/agents (escopo do projeto ou global)
