### Sempre inicialize o projeto
Execute o comando /init para iniciar um projeto

Ao executar um init, será criado um CLAUDE.md.
Todo repositório do claude possui um claude.md.

O claude.md fornece orientações ao Claude Code (claude.ai/code) ao trabalhar com código no repositório.

Em cada sesão do claude, o conteúdo do claude.md é inserido.
Ou seja, em cada prompt o claude considera o conteúdo do claude.md.

No claude.md deve ter regras gerais, estrutura e etc. 
Deve descrever o projeto para que o agente seja inteligente e 
consiga seguir um padrão de desenvolvimento entre seções.
