# Comandos e contexto da LLM

Para visualizar o contexto da LLM use o comando /context no terminal do claude code

A janela de contexto pode ser entendido como a memória da IA.
Mantém o cerébro fresco.

Sempre antes de pedir algo para a IA, verifique se você possui contexto disponível. Atingir o limite de contexto durante uma tarefa fará com que a IA
alucine.

---

### Comandos

#### /btw

Caso você queira perguntar ao claude algo enquanto ele executa uma tarefa,
execute o comando /btw sua mensagem aqui, o claude lhe responderá sem interromper
a tarefa.

#### /new ou /clear

Inicia uma nova janela de contexto.

#### /resume

Resume as conversas anteriores.

#### /compact

Compacta o contexto para liberar espaço na janela de contexto.
