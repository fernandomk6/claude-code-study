### O que é?

- Ele funciona como um agente de código
    - Tem autonomia para executar tarefas, como criar e editar arquivos. Cada agente usa um modelo, sendo o modelo uma veriante do LLM, exemplo claude Opus, claude Sonnet etc.

### Você orquestra mais do que escreve código na mão

- Você define arquitetura
- Você define decisão técnica
- Você define a regra de negócio
- Você aprova / reprova
