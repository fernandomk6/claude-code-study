# Slash commands com skills

## Commands vs Skills

| | commands | Skills |
| Acionado por /comando | S | S |
| Acionado automaticamento | N | S |
| Carregado sempre na memoria | N | N |

- Commands: Precisa ser invocado diretamente pelo usuário.
- Skills: O claude pode inferir quando usar.

Pode referenciar outras skills, rules, subagents e etc, commands possuem
escopo fechado.
