# Comando loop e goal

## /loop

Ideal para tarefas com cadência fixa.
Ele cria um cron job.

Um cron job é uma tarefa agendada para rodar automaticamente em horários definidos

### Exemplo /loop
30 minuto verifica a integração tasks se tem uma nova task aberta para
ser implementada
`/loop [intervalo] [prompt]`
O intervalo mínimo é 1m (1 minuto)

### Cancelando loops
/loop --cancel

## /goal

Por condição verificável um modelo avaliador checa após
cada turno se a condição foi atingida.

Um modelo rápido sepadado avalia a condição e libera o controle
quando ela for verdadeira.

Trabalho com estado final verificavel:
todos oss tetes passando, backlog, zerado, PR pronto

Maior pode rodar por horas ou dias sem atingir a condição.
Inclua limites.

### Exemplo /goal

/goal Implemente o componente depoimentos do petshop e também o component
     contatos com formulário de contato, atenção a boas práticas de código e separando
     componentes com resposabilidade única. Finalize quando os componentes estiverem
     implementados e corretos sem erros de execução ou pare em 20 turnos.
